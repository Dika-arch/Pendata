Missing Values Inputation Dengan WKNN#

1. Hitung Manual Excel#

Hitung nilai minimum dan maksimum#

  1. Nilai minimum dari Jam_Belajar =MIN(B5:B9)

  2. Nilai Maksimum Jam_Belajar =MAX(B5:B9)

  1. Nilai Minimum Kehadiran =MIN(C5:C9)

  2. Nilai Maksimum Kehadiran =MAX(C5:C9)

Diketahui:

Normalisasi data#

rumus Min-Max:

Artinya:

nilai asli dikurangi nilai minimum

lalu dibagi selisih max dan min

1. Hitung Min-Max Jam_Belajar#

E5 =(B5-N5)/(N6-N5) =(2-2)/(8-2) =0/6 =0

E6 =(B6-N5)/(N6-N5) =(4-2)/(8-2) =2/6 =0,333333

E7 =(6-2)/(8-2) =4/6 =0,666667

E8 =(8-2)/(8-2) =6/6 =1

E9 =(5-2)/(8-2) =3/6 =0,5

2. Hitung Min-Max Kehadiran#

F5 =(C5-O5)/(O6-O5) =(60-60)/(90-60) =0/30=0

F6 =(70-60)/(90-60) =10/30 =0,333333

F7 =(80-60)/(90-60) =20/30 =0,666667

F8 =(90-60)/(90-60) =30/30 =1

F9 =(75-60)/(90-60) =15/30 =0,5

Tentukan target yang akan dicari#

Target adalah S5, karena Nilai_UAS-nya kosong.

Jadi data target:

Jam_MinMax S5 = E9 = 0,5

Kehadiran_MinMax S5 = F9 = 0,5

Semua baris S1–S4 akan dibandingkan ke S5.

Hitung selisih terhadap target#

1. Selisih Jam_Belajar#

G5 =E5-E9 =0-0,5 =-0,5

G6 =0,333333-0,5 =-0,166667

G7 =0,666667-0,5 =0,166667

G8 =1-0,5 =0,5

2. Selisih Kehadiran#

H5 =F5-F9 =0-0,5 =-0,5

H6 =0,333333-0,5 =-0,166667

H7 =0,666667-0,5 =0,166667

H8 =1-0,5 =0,5

Diketahui:

Hitung jarak kuadrat#

Rumus:

I5 =G5^2+H5^2 =(-0,5)^2+(-0,5)^2 =0,25+0,25 =0,5

I6 =(-0,166667)^2+(-0,166667)^2 =0,027778+0,027778 =0,055556

I7 =(0,166667)^2+(0,166667)^2 =0,027778+0,027778 =0,055556

I8 =(0,5)^2+(0,5)^2 =0,25+0,25 =0,5

Diketahui:

Hitung bobot WKNN#

Rumus:

J5 =1/I5 =1/0,5 =2

J6 =1/0,055556 =18

J7 =1/0,055556 =18

J8 =1/0,5 =2

Diketahui:

Hitung bobot × nilai#

Rumus:

K5 =J5D5 =265 =130

K6 =18*70 =1260

K7 =18*80 =1440

K8 =2*90 =180

Diketahui:

Jumlahkan total bobot dan total pembilang#

1. Total Bobot#

=SUM(J5:J8)

=2+18+18+2

=40

2. Total Pembilang#

=SUM(K5:K8)

=130+1260+1440+180

=3010

Hitung hasil imputasi missing value#

Rumus akhir WKNN:

=K10/J10

=3010/40

=75,25

Code Menghitung WKNN#

import numpy as np
import pandas as pd
from sklearn.preprocessing import MinMaxScaler, StandardScaler, Normalizer

# ==============================================
# SOAL 1
# Missing value imputation dengan WKNN
# Normalisasi yang dipakai: Min-Max
# ==============================================

data = pd.DataFrame({
    'ID': ['S1', 'S2', 'S3', 'S4', 'S5'],
    'Jam_Belajar': [2, 4, 6, 8, 5],
    'Kehadiran': [60, 70, 80, 90, 75],
    'Nilai_UAS': [65, 70, 80, 90, np.nan]
})

print('=== DATA ASLI ===')
print(data)
print()

# Normalisasi Min-Max untuk fitur yang dipakai menghitung jarak
fitur = data[['Jam_Belajar', 'Kehadiran']]
scaler = MinMaxScaler()
fitur_norm = scaler.fit_transform(fitur)
fitur_norm = pd.DataFrame(fitur_norm, columns=['Jam_MinMax', 'Kehadiran_MinMax'])

print('=== HASIL NORMALISASI MIN-MAX ===')
print(pd.concat([data[['ID']], fitur_norm], axis=1))
print()

# Data target adalah baris dengan Nilai_UAS yang hilang
idx_target = data['Nilai_UAS'].isna()
target = fitur_norm[idx_target].iloc[0]

tetangga = fitur_norm[~idx_target].reset_index(drop=True)
nilai_tetangga = data.loc[~idx_target, 'Nilai_UAS'].reset_index(drop=True)
id_tetangga = data.loc[~idx_target, 'ID'].reset_index(drop=True)

# Hitung selisih, jarak kuadrat, bobot, dan bobot x nilai
hasil = pd.DataFrame({
    'ID': id_tetangga,
    'Jam_MinMax': tetangga['Jam_MinMax'],
    'Kehadiran_MinMax': tetangga['Kehadiran_MinMax'],
    'Nilai_UAS': nilai_tetangga,
})

hasil['Selisih_Jam'] = hasil['Jam_MinMax'] - target['Jam_MinMax']
hasil['Selisih_Keh'] = hasil['Kehadiran_MinMax'] - target['Kehadiran_MinMax']
hasil['Jarak_Kuadrat'] = hasil['Selisih_Jam']**2 + hasil['Selisih_Keh']**2
hasil['Bobot'] = 1 / hasil['Jarak_Kuadrat']
hasil['Bobot_x_Nilai'] = hasil['Bobot'] * hasil['Nilai_UAS']

print('=== TABEL PERHITUNGAN WKNN ===')
print(hasil)
print()

# Weighted average
prediksi = hasil['Bobot_x_Nilai'].sum() / hasil['Bobot'].sum()
print(f'Hasil imputasi missing value Nilai_UAS untuk S5 = {prediksi:.2f}')
print()

2. Normalisasi data#

Normalisasi adalah proses mengubah data ke skala yang lebih seragam supaya fitur bisa dibandingkan dengan adil. Ini penting terutama untuk metode berbasis jarak seperti KNN/WKNN. Secara umum, beberapa jenis normalisasi yang sering dipakai adalah Min-Max, Z-Score/Standardization, Decimal Scaling, dan Normalizer. sklearn.preprocessing menyediakan MinMaxScaler, StandardScaler, dan Normalizer untuk itu.

import pandas as pd
import numpy as np

# Dataset
data = pd.DataFrame({
    'ID': ['S1', 'S2', 'S3', 'S4', 'S5'],
    'Jam_Belajar': [2, 4, 6, 8, 5],
    'Kehadiran': [60, 70, 80, 90, 75]
})

def minmax_manual(kolom):
    return (kolom - kolom.min()) / (kolom.max() - kolom.min())

def zscore_manual(kolom):
    return (kolom - kolom.mean()) / kolom.std(ddof=0)

def decimal_scaling(kolom):
    j = int(np.ceil(np.log10(kolom.abs().max())))
    return kolom / (10 ** j)

# Hitung hasil
hasil_minmax = pd.DataFrame({
    'ID': data['ID'],
    'Jam_MinMax': minmax_manual(data['Jam_Belajar']),
    'Kehadiran_MinMax': minmax_manual(data['Kehadiran'])
})

hasil_zscore = pd.DataFrame({
    'ID': data['ID'],
    'Jam_Z': zscore_manual(data['Jam_Belajar']),
    'Kehadiran_Z': zscore_manual(data['Kehadiran'])
})

hasil_decimal = pd.DataFrame({
    'ID': data['ID'],
    'Jam_Decimal': decimal_scaling(data['Jam_Belajar']),
    'Kehadiran_Decimal': decimal_scaling(data['Kehadiran'])
})

# Print
print(" DATA ASLI ")
print(data.to_string(index=False))

print("\n HASIL MIN-MAX NORMALIZATION ")
print(hasil_minmax.round(4).to_string(index=False))

print("\n HASIL Z-SCORE NORMALIZATION ")
print(hasil_zscore.round(4).to_string(index=False))

print("\n HASIL DECIMAL SCALING ")
print(hasil_decimal.round(4).to_string(index=False))
