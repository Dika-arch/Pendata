Analisa Data Kesuburan Tanah dengan KNN#

##Pemrosesan Data

Sebelum model KNN dijalankan, dilakukan beberapa tahap pemrosesan data sebagai berikut:

  1. Membaca Dataset

Dataset dibaca menggunakan node Excel Reader pada KNIME. Tahap ini bertujuan untuk memasukkan data dari file Excel ke dalam workflow agar dapat diproses lebih lanjut.

Gambar Workflow KNIME Analisa Data Kesuburan Tanah

Menangani Missing Value#

Karena dataset memiliki beberapa data kosong, maka dilakukan penanganan missing value menggunakan node Missing Value. Langkah ini penting agar data dapat diproses oleh algoritma klasifikasi tanpa error dan agar kualitas data menjadi lebih baik.

Pada tahap penanganan missing value, atribut numerik bertipe integer dan float diisi menggunakan mean karena mean mewakili nilai rata-rata data sehingga dapat menggambarkan kondisi umum kolom tersebut. Pendekatan ini membantu menjaga distribusi data dan menghindari kehilangan baris data. Sementara itu, atribut bertipe string diisi menggunakan most frequent value karena data kategorikal tidak dapat dihitung rata-ratanya. Oleh sebab itu, nilai yang hilang diganti dengan kategori yang paling sering muncul agar tetap konsisten dengan karakteristik data asli.

##Transformasi Data Kategorikal

Atribut Tekstur Tanah merupakan atribut kategorikal, sehingga harus diubah menjadi bentuk numerik agar dapat digunakan oleh KNN. Pada KNIME, proses ini dilakukan dengan node One to Many, sehingga satu kolom kategorikal diubah menjadi beberapa kolom numerik biner.

Gambar Konfigurasi One to Many untuk atribut Tekstur Tanah

Pada tahap ini, atribut Tekstur Tanah dipilih sebagai kolom yang ditransformasikan karena bertipe kategorikal. Sementara itu, kolom Label tidak diubah karena merupakan target klasifikasi.

Pemilihan Kolom#

Setelah transformasi data, dilakukan pemilihan atribut menggunakan node Column Filter. Tahap ini bertujuan untuk memastikan hanya atribut yang relevan yang digunakan dalam proses klasifikasi.

Pada tahap Column Filter, dilakukan pemilihan atribut yang akan digunakan dalam proses klasifikasi. Kolom ID dikeluarkan karena hanya berfungsi sebagai penanda data dan tidak memiliki pengaruh terhadap klasifikasi. Selain itu, kolom asli Tekstur Tanah yang masih bertipe string juga dikeluarkan, karena algoritma KNN membutuhkan data numerik untuk menghitung jarak. Atribut tersebut telah diubah sebelumnya menjadi beberapa kolom numerik biner melalui proses One to Many, sehingga yang digunakan dalam model adalah kolom hasil transformasinya.

Normalisasi Data#

Karena algoritma KNN berbasis perhitungan jarak, maka seluruh atribut numerik perlu dinormalisasi agar memiliki skala yang sebanding. Pada penelitian ini, normalisasi dilakukan menggunakan node Normalizer.

Pada tahap normalisasi data, digunakan node Normalizer untuk menyamakan skala nilai pada atribut numerik sebelum proses klasifikasi menggunakan KNN. Hal ini penting karena algoritma KNN bekerja berdasarkan perhitungan jarak antar data, sehingga atribut dengan rentang nilai yang lebih besar dapat mendominasi hasil klasifikasi jika data tidak dinormalisasi. Pada penelitian ini digunakan metode Z-score, yaitu mengubah setiap nilai data berdasarkan rata-rata dan standar deviasi atributnya. Dengan normalisasi ini, seluruh atribut numerik memiliki skala yang lebih sebanding, sehingga proses klasifikasi menjadi lebih adil dan akurat.

##Pembagian Data Training dan Testing

Setelah preprocessing selesai, dataset dibagi menjadi dua bagian menggunakan node Table Partitioner, yaitu:

data training untuk melatih model

data testing untuk menguji model

Setelah itu dilakukan proses klasifikasi menggunakan node K Nearest Neighbor, dan hasil prediksi dibandingkan dengan label asli menggunakan node Scorer.

Setelah tahap preprocessing selesai, dataset dibagi menjadi dua bagian menggunakan node Table Partitioner, yaitu 80% data training dan 20% data testing. Pembagian dilakukan dengan metode stratified sampling berdasarkan kolom Label, sehingga proporsi kelas Subur dan Tidak Subur tetap terjaga baik pada data training maupun data testing. Penggunaan stratified sampling penting agar distribusi kelas pada kedua bagian data tetap seimbang dan hasil evaluasi model menjadi lebih valid. Selain itu, opsi fixed random seed diaktifkan agar proses pembagian data bersifat konsisten setiap kali workflow dijalankan.

##Implementasi KNN pada KNIME

Pada KNIME, alur analisis dilakukan dengan urutan node sebagai berikut:

Excel Reader → Missing Value → One to Many → Column Filter → Normalizer → Table Partitioner → K Nearest Neighbor → Scorer

Tahapan ini menunjukkan bahwa data telah melalui preprocessing terlebih dahulu sebelum digunakan dalam proses klasifikasi. Setelah model KNN dijalankan, hasil evaluasi diperoleh melalui node Scorer.

Pada tahap klasifikasi digunakan node K Nearest Neighbor dengan kolom target Label. Kolom ini berisi kelas yang akan diprediksi, yaitu Subur dan Tidak Subur. Nilai parameter k = 5 menunjukkan bahwa proses prediksi dilakukan dengan mempertimbangkan 5 tetangga terdekat dari setiap data uji. Kelas data uji ditentukan berdasarkan mayoritas kelas dari lima tetangga tersebut. Opsi weight neighbors by distance tidak digunakan, sehingga setiap tetangga memiliki bobot yang sama dalam proses voting. Selain itu, opsi output class probabilities juga tidak diaktifkan karena penelitian ini berfokus pada hasil klasifikasi akhir dan metrik evaluasi.

##Hasil Evaluasi

Hasil evaluasi diperoleh dari node Scorer dalam bentuk Confusion Matrix dan Accuracy Statistics.

Berdasarkan hasil evaluasi pada node Scorer, diperoleh nilai Accuracy = 1.00, Precision = 1.00, Recall = 1.00, dan F1-Score = 1.00. Jika dinyatakan dalam persen, seluruh metrik tersebut bernilai 100%. Hal ini menunjukkan bahwa model KNN mampu mengklasifikasikan seluruh data uji dengan benar tanpa kesalahan prediks
