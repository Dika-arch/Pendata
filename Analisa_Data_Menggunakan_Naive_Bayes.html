Analisa Data Menggunakan Naive Bayes#

1. Gambaran#

Analisis data menggunakan Naive Bayes. Model classifier tidak dibuat dengan node Naive Bayes bawaan KNIME, melainkan dibuat dengan Python Script menggunakan library scikit-learn.

Pada praktik ini, workflow yang digunakan adalah:

Excel Reader (Training) ─┐
                         ├── Python Script ─── Scorer
Excel Reader (Testing)  ─┘

Makna alur tersebut:

  1. Excel Reader pertama membaca data training.

  2. Excel Reader kedua membaca data testing.

  3. Python Script membuat model Gaussian Naive Bayes menggunakan sklearn.

  4. Scorer mengevaluasi hasil prediksi.

Jadi, KNIME dipakai sebagai tempat menyusun alur kerja, sedangkan model Naive Bayes tetap dibuat melalui script Python.

2. Apa Itu Klasifikasi?#

Klasifikasi adalah proses memasukkan data ke dalam kelas tertentu. Dalam praktik ini, kelas yang diprediksi adalah:

lulus
tidak

Model menerima data mahasiswa, lalu model menentukan apakah mahasiswa tersebut masuk kelas lulus atau tidak.

Fitur yang dipakai untuk memprediksi kelas adalah:

Fitur

Makna

jam_belajar

Jumlah jam belajar mahasiswa

kehadiran

Tingkat kehadiran mahasiswa

nilai_tugas

Nilai tugas mahasiswa

jumlah_bimbingan

Jumlah bimbingan yang diikuti

Target yang diprediksi adalah:

status_lulus

3. Apa Itu Naive Bayes?#

Naive Bayes adalah algoritma klasifikasi berbasis probabilitas. Model ini menghitung peluang suatu data masuk ke kelas tertentu, lalu memilih kelas dengan peluang terbesar.

Rumus dasar Teorema Bayes adalah:

\[ P(C_i|X) = \frac{P(X|C_i) \times P(C_i)}{P(X)} \]

Penjelasan sederhananya:

Bagian

Arti

\(C_i\)

Kelas yang ingin diprediksi, misalnya lulus atau tidak

\(X\)

Data mahasiswa yang memiliki fitur tertentu

$P(C_i

X)$

$P(X

C_i)$

\(P(C_i)\)

Peluang awal suatu kelas

\(P(X)\)

Peluang data secara umum

Bahasa sederhananya:

Naive Bayes menebak kelas dengan melihat peluang. Jika peluang lulus lebih besar daripada tidak, maka model memprediksi lulus.

4. Memakai Gaussian Naive Bayes#

Naive Bayes memiliki beberapa jenis. Pada praktik ini, digunakan Gaussian Naive Bayes karena fitur yang dipakai berbentuk angka.

Fitur numerik pada data:

Fitur

Bentuk Data

jam_belajar

Angka

kehadiran

Angka

nilai_tugas

Angka

jumlah_bimbingan

Angka

Karena semua fitur input berbentuk angka, model yang cocok adalah:

GaussianNB()

Gaussian Naive Bayes menganggap nilai fitur mengikuti pola distribusi normal atau Gaussian dalam setiap kelas.

5. Langkah Pertama: Siapkan Data Training dan Testing#

Pada praktik ini, data dibagi menjadi dua file Excel:

Fungsi

Data training digunakan agar model belajar pola antara fitur dan target. Data testing digunakan untuk melihat apakah model mampu memprediksi data baru dengan benar.

6. Data Training#

Data training berisi fitur numerik dan target status_lulus. Data inilah yang dipakai model untuk belajar.

7. Data Testing#

Data testing memiliki struktur kolom yang sama dengan data training. Perbedaannya, data testing digunakan untuk menguji model setelah model selesai dilatih.

Kolom status_lulus tetap ada pada data testing karena Scorer membutuhkan kelas aktual untuk membandingkan hasil prediksi.

8. Langkah Kedua: Susun Workflow di KNIME#

Workflow disusun seperti berikut:

Excel Reader (Training) ─┐
                         ├── Python Script ─── Scorer
Excel Reader (Testing)  ─┘

Penjelasan langkahnya:

  1. Tambahkan node Excel Reader pertama.

  2. Hubungkan file training ke Excel Reader pertama.

  3. Tambahkan node Excel Reader kedua.

  4. Hubungkan file testing ke Excel Reader kedua.

  5. Tambahkan node Python Script.

  6. Atur Python Script agar memiliki 2 input table dan 1 output table.

  7. Hubungkan kedua Excel Reader ke Python Script.

  8. Tambahkan node Scorer.

  9. Hubungkan output Python Script ke Scorer.

9. Langkah Ketiga: Masukkan Script Python#

Node Python Script bertugas membuat model Naive Bayes. Di dalam script, data training dan testing dibaca dari input KNIME.

Bagian pentingnya adalah:

train_df = knio.input_tables[0].to_pandas()
test_df = knio.input_tables[1].to_pandas()

Artinya:

Input

Isi

input_tables[0]

input_tables[1]

10. Script Lengkap untuk Python Script KNIME#

Salin script berikut ke node Python Script di KNIME.

# ==========================================================
# PRAKTIK: ANALISIS DATA MENGGUNAKAN GAUSSIAN NAIVE BAYES
# WORKFLOW: Excel Reader (Training) + Excel Reader (Testing)
#           -> Python Script -> Scorer
# MODEL: GaussianNB dari sklearn.naive_bayes
# ==========================================================

import knime.scripting.io as knio
import pandas as pd

from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix


# ==========================================================
# 1. MEMBACA DATA DARI EXCEL READER
# ==========================================================
# Input 0 = data training
# Input 1 = data testing

train_df = knio.input_tables[0].to_pandas()
test_df = knio.input_tables[1].to_pandas()


# ==========================================================
# 2. MENENTUKAN FITUR DAN TARGET
# ==========================================================

target_col = "status_lulus"

feature_cols = [
    "jam_belajar",
    "kehadiran",
    "nilai_tugas",
    "jumlah_bimbingan"
]

X_train = train_df[feature_cols]
y_train = train_df[target_col]

X_test = test_df[feature_cols]
y_test = test_df[target_col]


# ==========================================================
# 3. MEMBUAT DAN MELATIH MODEL GAUSSIAN NAIVE BAYES
# ==========================================================

model = GaussianNB()
model.fit(X_train, y_train)


# ==========================================================
# 4. MELAKUKAN PREDIKSI
# ==========================================================

y_pred = model.predict(X_test)


# ==========================================================
# 5. MEMBUAT OUTPUT UNTUK NODE SCORER
# ==========================================================
# Scorer membutuhkan kolom aktual dan kolom prediksi.
# Di Scorer, pilih:
# First column  = status_lulus
# Second column = prediction

output = test_df.copy()
output["prediction"] = y_pred
output["status_prediksi"] = output.apply(
    lambda row: "Benar" if row[target_col] == row["prediction"] else "Salah",
    axis=1
)


# ==========================================================
# 6. METRIK EVALUASI TAMBAHAN
# ==========================================================

accuracy = accuracy_score(y_test, y_pred)
precision = precision_score(y_test, y_pred, pos_label="lulus", zero_division=0)
recall = recall_score(y_test, y_pred, pos_label="lulus", zero_division=0)
f1 = f1_score(y_test, y_pred, pos_label="lulus", zero_division=0)

cm = confusion_matrix(y_test, y_pred, labels=["lulus", "tidak"])

print("Accuracy :", accuracy)
print("Precision:", precision)
print("Recall   :", recall)
print("F1-Score :", f1)
print("Confusion Matrix [lulus, tidak]:")
print(cm)


# ==========================================================
# 7. MENGIRIM OUTPUT KE KNIME
# ==========================================================

knio.output_tables[0] = knio.Table.from_pandas(output.astype(str))

11. Cara Membaca Script#

11.1 Membaca Data dari KNIME#

train_df = knio.input_tables[0].to_pandas()
test_df = knio.input_tables[1].to_pandas()

Perintah tersebut mengambil data dari Excel Reader dan mengubahnya menjadi DataFrame Pandas.

11.2 Menentukan Fitur dan Target#

feature_cols = ["jam_belajar", "kehadiran", "nilai_tugas", "jumlah_bimbingan"]
target_col = "status_lulus"

Fitur adalah kolom input yang digunakan untuk prediksi. Target adalah kolom tujuan yang ingin diprediksi.

11.3 Melatih Model#

model = GaussianNB()
model.fit(X_train, y_train)

Baris ini membuat model Gaussian Naive Bayes dan melatihnya menggunakan data training.

11.4 Melakukan Prediksi#

y_pred = model.predict(X_test)

Baris ini membuat prediksi untuk data testing.

11.5 Membuat Output untuk Scorer#

output["prediction"] = y_pred

Kolom prediction ditambahkan agar Scorer dapat membandingkan hasil prediksi dengan kolom aktual status_lulus.

12. Langkah Keempat: Atur Node Scorer#

Setelah Python Script berhasil dijalankan, hubungkan outputnya ke node Scorer.

Pada Scorer, pilih:

Pengaturan

Kolom

First column

status_lulus

Second column

prediction

Maknanya:

  • status_lulus adalah jawaban asli.

  • prediction adalah jawaban dari model.

Scorer membandingkan kedua kolom tersebut untuk menghasilkan confusion matrix.

13. Cara Membaca Confusion Matrix#

Hasil Scorer menunjukkan confusion matrix berikut.

Actual \ Prediction

tidak

lulus

tidak

4

0

lulus

0

6

Cara membacanya:

  1. Baris tidak, kolom tidak bernilai 4. Artinya, 4 data yang sebenarnya tidak berhasil diprediksi sebagai tidak.

  2. Baris lulus, kolom lulus bernilai 6. Artinya, 6 data yang sebenarnya lulus berhasil diprediksi sebagai lulus.

  3. Baris tidak, kolom lulus bernilai 0. Artinya, tidak ada data tidak yang salah diprediksi sebagai lulus.

  4. Baris lulus, kolom tidak bernilai 0. Artinya, tidak ada data lulus yang salah diprediksi sebagai tidak.

14. Cara Menghitung Accuracy#

Dari confusion matrix:

Prediksi benar = 4 + 6 = 10
Total data testing = 10

Maka:

\[ Accuracy = \frac{10}{10} = 1.0 \]

Dalam persentase:

\[ Accuracy = 100\% \]

Artinya, seluruh data testing berhasil diprediksi dengan benar.

15. Versi Kode untuk Jupyter Notebook#

Kode berikut bukan untuk KNIME, melainkan untuk menjalankan simulasi yang sama di Jupyter Notebook atau Jupyter Book. Data training dan testing dibuat langsung di dalam kode agar bisa dijalankan tanpa Excel Reader.

# ==========================================================
# GAUSSIAN NAIVE BAYES
# ==========================================================

import pandas as pd

from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix


# ==========================================================
# 1. MEMBUAT DATA TRAINING
# ==========================================================

train_df = pd.DataFrame({
    "jam_belajar": [2,3,4,2,5,6,7,8,9,10,11,12,5,7,3,9,4,10,6,2,8,11,5,7,3,12,4,9],
    "kehadiran": [55,60,62,50,65,70,75,80,85,90,92,95,68,78,58,88,64,91,73,52,83,94,66,77,57,96,63,86],
    "nilai_tugas": [50,55,58,45,60,68,72,78,82,88,90,94,63,76,52,86,59,89,70,48,80,92,61,74,54,95,57,84],
    "jumlah_bimbingan": [0,0,1,0,1,1,1,2,2,3,3,4,1,2,0,3,1,3,2,0,2,4,1,2,0,4,1,3],
    "status_lulus": ["tidak","tidak","tidak","tidak","tidak","lulus","lulus","lulus","lulus","lulus","lulus","lulus",
                     "tidak","lulus","tidak","lulus","tidak","lulus","lulus","tidak","lulus","lulus","tidak","lulus",
                     "tidak","lulus","tidak","lulus"]
})


# ==========================================================
# 2. MEMBUAT DATA TESTING
# ==========================================================

test_df = pd.DataFrame({
    "jam_belajar": [3,4,6,8,10,2,7,5,11,9],
    "kehadiran": [59,61,72,81,89,51,76,67,93,87],
    "nilai_tugas": [53,56,69,79,87,47,73,62,91,85],
    "jumlah_bimbingan": [0,1,1,2,3,0,2,1,4,3],
    "status_lulus": ["tidak","tidak","lulus","lulus","lulus","tidak","lulus","tidak","lulus","lulus"]
})


# ==========================================================
# 3. MEMISAHKAN FITUR DAN TARGET
# ==========================================================

target_col = "status_lulus"
feature_cols = ["jam_belajar", "kehadiran", "nilai_tugas", "jumlah_bimbingan"]

X_train = train_df[feature_cols]
y_train = train_df[target_col]

X_test = test_df[feature_cols]
y_test = test_df[target_col]


# ==========================================================
# 4. MEMBUAT DAN MELATIH MODEL
# ==========================================================

model = GaussianNB()
model.fit(X_train, y_train)


# ==========================================================
# 5. PREDIKSI DATA TESTING
# ==========================================================

y_pred = model.predict(X_test)

output = test_df.copy()
output["prediction"] = y_pred
output["status_prediksi"] = output.apply(
    lambda row: "Benar" if row[target_col] == row["prediction"] else "Salah",
    axis=1
)

display(output)


# ==========================================================
# 6. EVALUASI HASIL
# ==========================================================

accuracy = accuracy_score(y_test, y_pred)
precision = precision_score(y_test, y_pred, pos_label="lulus", zero_division=0)
recall = recall_score(y_test, y_pred, pos_label="lulus", zero_division=0)
f1 = f1_score(y_test, y_pred, pos_label="lulus", zero_division=0)
cm = confusion_matrix(y_test, y_pred, labels=["tidak", "lulus"])

print("Accuracy :", accuracy)
print("Precision:", precision)
print("Recall   :", recall)
print("F1-Score :", f1)
print("Confusion Matrix [tidak, lulus]:")
print(cm)
