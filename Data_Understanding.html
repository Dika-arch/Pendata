Mengukur Jarak#

Dalam tahap Business Understanding (CRISP-DM), pengukuran jarak digunakan untuk:

  • Segmentasi pelanggan (clustering)

  • Mendeteksi kemiripan produk

  • Rekomendasi berbasis similaritas

  • Deteksi anomali

Intinya:

Jarak kecil → objek mirip → bisa satu segmen Jarak besar → objek berbeda → beda cluster

Konsep dasar similarity dan dissimilarity :

  • Similarity → semakin besar semakin mirip (range 0–1)

  • Dissimilarity (distance) → semakin kecil semakin mirip

Mengukur Jarak Tipe Data Campuran

Apa itu Tipe Data Campuran?

Dataset disebut campuran jika dalam satu tabel terdapat:

  • Nominal (contoh: Status perkawinan)

  • Binary simetris (contoh: Gender)

  • Binary asimetris (contoh: Diabetes_Test)

  • Ordinal (contoh: Satisfaction)

  • Numerik (contoh: Height, Age)

Permasalahannya: Tidak semua tipe data bisa dihitung dengan rumus jarak yang sama.

Database nyata biasanya berisi:

  • Nominal (jenis kelamin)

  • Binary (ya/tidak)

  • Ordinal (ranking)

  • Numerik (umur, penghasilan)

Rumus Jarak Tipe Campuran:

Secara teori, jarak tipe campuran dihitung:

Aturannya:

Tipe Data

Cara Hitung

Numerik

Normalisasi → selisih absolut

Nominal

0 jika sama, 1 jika beda

Binary Asimetris

Gunakan Jaccard

Ordinal

Ranking → skala 0–1 → perlakukan numerik

  • Atribut Numerik

Dinormalisasi agar tidak mendominasi:

  • Atribut Nominal

  • Binary Simetris

0 jika sama, 1 jika beda.

  • Binary Asimetris

Gunakan Jaccard:

0-0 tidak dihitung.

  • Ordinal

Ubah ke ranking

Normalisasi ke [0,1]

Perlakukan seperti numerik

Analisis Menggunakan Orange Tipe Data Campuran#

1. Euclidean (Normalized)

Euclidean distance:

Tetapi karena dataset kamu campuran dan ada numerik dengan skala berbeda, Orange melakukan normalisasi min–max terlebih dahulu:

Artinya:

Height dan Age diskalakan ke 0–1

Tidak ada fitur yang mendominasi

Kemudian dihitung Euclidean seperti biasa.

1.1 Kenapa Harus Normalized?

Kalau tidak dinormalisasi:

Height (158–180)

Age (28–45)

Selisih bisa besar dan mendominasi. Binary hanya 0–1, jadi pengaruhnya kecil.

Normalized membuat kontribusi lebih seimbang.

1.2 Interpretasi Matrix

  • Nilai Diagonal = 0

Benar. Karena jarak objek ke dirinya sendiri = 0.

  • Matrix Simetris

Benar. Karena Euclidean bersifat simetris.

1.3 Pasangan Paling Mirip

Nilai terkecil (selain 0):

1.395 → Pasien 2 dan 4

Artinya: Pasien 2 dan 4 paling mirip.

Secara data:

  • Sama gender

  • Sama diabetes (negatif)

  • Satisfaction sama

  • Height & Age tidak jauh

1.4 Artinya Secara Konseptual?

Euclidean (normalized):

  • Menggabungkan semua atribut

  • Sensitif terhadap selisih numerik

  • Menganggap encoding kategori sebagai angka

Kekurangan:

Kategori sebenarnya tidak punya jarak matematis. Tetapi Euclidean memperlakukannya sebagai angka.

1.5 Catatan

Hasil Euclidean (normalized) menunjukkan bahwa pasangan pasien 2 dan 4 memiliki jarak terkecil (1.395), sehingga memiliki karakteristik paling mirip. Sebaliknya, pasien 2 dan 5 memiliki jarak terbesar (3.427), menunjukkan perbedaan signifikan. Normalisasi memastikan atribut numerik tidak mendominasi perhitungan jarak.

Euclidean (normalized):

Cocok untuk melihat kemiripan global

Tetapi bukan metode ideal untuk data campuran murni

2. Hamming

Rumus:

2.1 Interpretasi Matrix

Nilai yang muncul:

  • 0.571

  • 0.714

  • 0.857

  • 1.000

Dataset kamu punya 7 fitur (tanpa ID):

  • Gender

  • Diabetes_Test

  • Marital_Status

  • Satisfaction

  • Height_cm

  • Age

Jadi total fitur = 6

2.2 Contoh Perhitungan

  • Nilai 0.571

4/7≈0.571

Artinya: 4 atribut berbeda dari total fitur.

  • Nilai 0.714

5/7≈0.714

Artinya: 5 atribut berbeda.

  • Nilai 0.857

6/7≈0.857

Artinya: 6 dari 7 atribut berbeda

  • Nilai 1.000

Semua atribut berbeda.

2.3 Analisis dari Matrix

  • Pasangan Paling Mirip

Nilai terkecil = 0.571

Artinya hanya sekitar 4 fitur berbeda.

Contoh:

Pasien 1 dan 5 = 0.571 Berarti relatif mirip.

  • Pasangan Paling Berbeda

Nilai = 1.000 Semua fitur berbeda.

2.4 Catatan

Hamming distance mengukur proporsi atribut yang berbeda antar objek. Nilai 0.571 menunjukkan sekitar 4 dari total atribut berbeda. Metode ini cocok untuk data campuran karena tidak bergantung pada skala numerik, namun tidak mempertimbangkan besar selisih pada atribut numerik.

3. Jaccard

Jaccard digunakan untuk binary asimetris.

Rumus jarak:

Dimana:

  • q = jumlah 1–1 (keduanya positif)

  • r = 1–0

  • s = 0–1

  • 0–0 tidak dihitung

Intinya:

Fokus pada nilai 1 (kejadian penting)

Dalam kasus :

  • Positif = kondisi penting

  • Negatif = tidak dihitung jika sama-sama negatif

3.1 Matrix Hanya 0 dan 1

Karena hanya pakai 1 kolom binary.

Kondisi

Jarak

Positif – Positif

0

Negatif – Negatif

0

Positif – Negatif

1

Tidak mungkin muncul 0.5 karena hanya 1 fitur.

3.2 Contoh Perhitungan Manual

Misal:

Pasien 1 = Positif (1)

Pasien 2 = Negatif (0)

Maka:

r+s = 1

q+r+s = 1

d=1/1=1

Pasien 1 = Positif

Pasien 5 = Positif

q = 1

r+s = 0

d=0/1=0

Misal:

Pasien 2 = Negatif

Pasien 4 = Negatif

0–0 diabaikan

Hasil = 0

3.3 Interpretasi Matrix

Lihat pola:

1–5 = 0 → Sama-sama Positif

2–4 = 0 → Sama-sama Negatif

2–6 = 0 → Sama-sama Negatif

Nilai 1 muncul jika satu positif dan satu negatif.

3.4 Catatan

Jaccard distance digunakan untuk atribut binary asimetris (Diabetes_Test). Hasil hanya 0 atau 1 karena hanya satu atribut binary yang digunakan. Nilai 0 menunjukkan kondisi diabetes yang sama, sedangkan nilai 1 menunjukkan perbedaan status. Metode ini lebih tepat untuk data medis karena hanya mempertimbangkan kejadian positif.

Analisis Perbandingan Distance Metric pada Dataset Iris Menggunakan Orange#

###1. Euclidean

Rumus

1.1 Apa yang Diukur?

Jarak geometris lurus antar dua bunga di ruang 4 dimensi.

1.2 Cara Membaca Matrix Kamu

  • Nilai kecil (misal 0.141, 0.173) → bunga sangat mirip

  • Nilai besar (misal >1.5) → bunga berbeda jauh

  • Diagonal = 0

  • Matrix simetris

1.3 Interpretasi pada Iris

  • Setosa biasanya saling dekat (nilai kecil)

  • Setosa vs Virginica → jarak besar

  • Versicolor dan Virginica → jarak sedang

1.4 Karakteristik

  • Sensitif terhadap besar selisih

  • Cocok untuk clustering berbasis bentuk geometris

2. MANHATTAN#

Rumus

2.1 Apa yang Diukur?

Total selisih absolut tiap fitur.

2.2 Cara Membaca

Nilai lebih besar dari Euclidean karena tidak diakar.

Contoh:

Euclidean ≈ 0.5

Manhattan ≈ 0.8

2.3 Interpretasi

Pola kemiripan biasanya sama dengan Euclidean, hanya skalanya berbeda.

2.4 Karakteristik

  • Lebih tahan terhadap outlier

  • Tidak terlalu menghukum perbedaan besar

3. COSINE#

Rumus

3.1 yang Diukur

Sudut antar dua vektor.

Bukan besar selisih, tapi arah pola fitur.

3.2 Cara Membaca Matrix

Nilai sangat kecil (0.000–0.005)

Artinya: Hampir semua bunga memiliki arah pola yang mirip.

3.3 Interpretasi

  • Cosine fokus proporsi relatif

  • Tidak terlalu peduli ukuran absolut

3.4 Karakteristik

  • Cocok untuk data berdimensi tinggi

  • Cocok untuk teks

  • Kurang sensitif magnitude

4. MAHALANOBIS#

Rumus

S = matriks kovarian

4.1 yang Diukur

Jarak dengan mempertimbangkan:

  • Korelasi antar fitur

  • Variansi fitur

4.2 Kenapa Nilainya Berbeda?

Karena:

Jika dua fitur sangat berkorelasi, kontribusinya tidak dihitung dua kali.

4.3 Interpretasi pada Iris

Mahalanobis sering:

  • Memisahkan cluster lebih jelas

  • Lebih akurat untuk data statistik

4.4 Karakteristik

  • Memperhitungkan korelasi

  • Lebih “ilmiah” secara statistik

  • Lebih kompleks

5. PEARSON#

Rumus

Berbasis korelasi:

Dimana r = koefisien korelasi Pearson.

5.1 yang Diukur

Hubungan linear antar dua vektor.

5.2 Cara Membaca

  • Nilai kecil → pola linear sangat mirip

  • Nilai besar → pola berbeda

5.3 Interpretasi

Jika dua bunga naik turun bersama di semua fitur → jarak kecil.

5.4 Karakteristik

  • Fokus hubungan linear

  • Tidak peduli skala absolut
