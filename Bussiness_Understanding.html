Apa Itu Missing Values?#

Missing values adalah data yang kosong, hilang, atau tidak terisi dalam suatu dataset.

Contoh:

Nilai kosong

NaN (Not a Number)

Null

Untuk Apa Cek Missing Values?

Cek missing values dilakukan untuk memastikan:

1️⃣ Data Lengkap

Jika ada data kosong, maka:

Perhitungan mean bisa salah

Korelasi bisa bias

Model machine learning bisa error

2️⃣ Menghindari Error Perhitungan

Banyak algoritma tidak bisa memproses data kosong.

Contoh:

K-Means tidak menerima NaN

Regresi bisa gagal

3️⃣ Menentukan Tindakan

Jika ditemukan missing values, biasanya dilakukan:

Menghapus baris data

Mengisi dengan mean/median

Mengisi dengan nilai tertentu

Apa Itu Scatter Plot?#

Scatter plot adalah grafik yang menampilkan hubungan antara dua variabel numerik.

Sumbu X → variabel pertama

Sumbu Y → variabel kedua

Titik → satu data (satu bunga)

Scatter plot digunakan untuk:

Melihat pola hubungan

Melihat korelasi

Melihat pemisahan kelas

Melihat cluster alami

🔎 Interpretasi 1️⃣ Terlihat 3 Kelompok

Jika diberi warna berdasarkan species:

Iris-setosa → terpisah jelas

Iris-versicolor → di tengah

Iris-virginica → paling besar

Artinya: Petal_length dan petal_width sangat efektif membedakan spesies.

2️⃣ Hubungan Linear Positif

Titik-titik membentuk pola naik.

Artinya: Semakin panjang petal, semakin lebar petal.

Ini sesuai dengan nilai korelasi tinggi (~0.96).

3️⃣ Tidak Ada Outlier Ekstrem

Tidak terlihat titik yang jauh menyimpang.

Artinya: Data bersih dan stabil.

Kesimpulan Scatter Plot

Scatter plot menunjukkan bahwa atribut petal_length dan petal_width memiliki hubungan linear positif yang kuat serta mampu memisahkan spesies Iris dengan jelas, terutama Iris-setosa. Sebaliknya, atribut sepal menunjukkan pemisahan yang kurang jelas.

Penjelasan Korelasi#

Apa Itu Korelasi?

Korelasi adalah ukuran yang menunjukkan seberapa kuat hubungan antara dua variabel numerik.

Nilai korelasi berada di antara:

+1 → hubungan positif sangat kuat

0 → tidak ada hubungan

-1 → hubungan negatif sangat kuat

Jika nilai mendekati:

1 → semakin besar X, semakin besar Y

-1 → semakin besar X, semakin kecil Y

Pada analisis ini digunakan Pearson correlation, yaitu untuk mengukur hubungan linear antar variabel.

📈 Hasil Korelasi Dataset Iris (Pearson)

Nilai utama yang diperoleh:

petal_length ↔ petal_width ≈ 0.96

sepal_length ↔ petal_length ≈ 0.87

sepal_length ↔ petal_width ≈ 0.82

sepal_width ↔ petal_length ≈ -0.42

sepal_width ↔ petal_width ≈ -0.36

sepal_length ↔ sepal_width ≈ -0.11

🔎 Interpretasi 1️⃣ Hubungan Terkuat

Petal_length dan petal_width memiliki korelasi sangat kuat (≈0.96).

Artinya: Semakin panjang petal, semakin lebar petal.

Variabel ini hampir bergerak bersama.

2️⃣ Hubungan Kuat

Sepal_length dengan petal_length (≈0.87).

Artinya: Bunga dengan sepal panjang cenderung memiliki petal lebih panjang.

3️⃣ Korelasi Negatif Sedang

Sepal_width dengan petal_length (≈ -0.42).

Artinya: Semakin lebar sepal, cenderung petal lebih pendek.

Namun hubungan ini tidak terlalu kuat.

4️⃣ Korelasi Lemah

Sepal_length dengan sepal_width (≈ -0.11).

Artinya: Hampir tidak ada hubungan antara panjang dan lebar sepal.

Atribut Dataset Iris#

Dataset Iris memiliki 5 kolom:

4 atribut numerik (fitur)

1 atribut kategori (class/species)

Semua pengukuran dalam satuan cm (centimeter).

1️⃣ Sepal Length

Sepal length adalah panjang kelopak bunga.

Kelopak (sepal) adalah bagian luar bunga yang melindungi kuncup saat masih tertutup.

Karakteristik:

Nilai berkisar ± 4.3 – 7.9 cm

Rata-rata sekitar 5.84 cm

Berbeda antar spesies

Biasanya:

Iris-virginica memiliki sepal lebih panjang

Iris-setosa lebih pendek

2️⃣ Sepal Width

Sepal width adalah lebar kelopak bunga.

Karakteristik:

Nilai berkisar ± 2.0 – 4.4 cm

Rata-rata sekitar 3.05 cm

Korelasinya lemah dibanding atribut lain

Sepal width kurang kuat dalam membedakan spesies dibanding petal.

3️⃣ Petal Length

Petal length adalah panjang mahkota bunga.

Mahkota (petal) adalah bagian bunga yang biasanya berwarna dan menarik penyerbuk.

Karakteristik:

Nilai berkisar ± 1.0 – 6.9 cm

Rata-rata sekitar 3.76 cm

Memiliki korelasi sangat kuat dengan petal width (~0.96)

Atribut ini sangat penting untuk klasifikasi karena:

Iris-setosa memiliki petal sangat pendek

Iris-virginica paling panjang

4️⃣ Petal Width

Petal width adalah lebar mahkota bunga.

Karakteristik:

Nilai berkisar ± 0.1 – 2.5 cm

Rata-rata sekitar 1.20 cm

Sangat berkorelasi dengan petal length

Semakin panjang petal, biasanya semakin lebar.

5️⃣ Species (Class)

Atribut kategori yang menunjukkan jenis bunga:

Iris-setosa

Iris-versicolor

Iris-virginica

Masing-masing memiliki 50 data (total 150).

##Histogram Py Perbedaan tampilan histogram antara Python dan Orange disebabkan oleh perbedaan metode pembagian interval (binning) serta perbedaan sistem visualisasi masing-masing perangkat lunak. Meskipun bentuk grafik terlihat berbeda, nilai statistik seperti minimum, maksimum, dan rata-rata tetap sama, sehingga dapat disimpulkan bahwa dataset yang digunakan identik dan distribusi datanya konsisten.

import seaborn as sns
import matplotlib.pyplot as plt

features = ["sepal_length", "sepal_width",
            "petal_length", "petal_width"]

for feature in features:
    plt.figure(figsize=(6,4))
    sns.histplot(data=df, x=feature, hue="species",
                 bins=10, kde=False)
    plt.title(f"Histogram {feature}")
    plt.show()

##Histogram orange

##Penjelasan Histogram Histogram adalah grafik yang menunjukkan distribusi frekuensi suatu variabel numerik.

Sumbu X → nilai atribut (misalnya sepal_length)

Sumbu Y → jumlah/frekuensi data

Data dibagi dalam beberapa interval (bin)

Histogram digunakan untuk melihat:

Pola distribusi

Penyebaran data

Apakah data normal / miring

Apakah ada outlier

📈 Penjelasan Histogram pada Dataset Iris 1️⃣ Sepal Length

Rentang: 4.3 – 7.9 cm

Distribusi relatif menyebar merata

Terlihat sedikit pengelompokan di nilai tengah

Artinya: Panjang sepal memiliki variasi cukup besar antar spesies.

2️⃣ Sepal Width

Rentang: 2.0 – 4.4 cm

Distribusi lebih terpusat di sekitar 3 cm

Tidak terlalu menyebar

Artinya: Lebar sepal cenderung stabil dan tidak terlalu bervariasi.

3️⃣ Petal Length

Rentang: 1.0 – 6.9 cm

Terlihat pemisahan distribusi yang jelas

Ada kelompok nilai rendah (setosa) dan kelompok nilai tinggi (versicolor & virginica)

Artinya: Petal length sangat membedakan spesies.

4️⃣ Petal Width

Rentang: 0.1 – 2.5 cm

Distribusi juga menunjukkan pemisahan yang cukup jelas

Sangat berkorelasi dengan petal length

Artinya: Petal width menjadi variabel penting dalam klasifikasi.

🔎 Apakah Ada Outlier?

Dari histogram:

Tidak terlihat nilai ekstrem yang jauh dari distribusi utama.

Data relatif bersih.
